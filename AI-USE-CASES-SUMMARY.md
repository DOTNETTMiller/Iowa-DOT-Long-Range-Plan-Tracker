## How to Update Use Cases

### Via Admin UI (Recommended):
1. Go to AI Strategy tab
2. Click "➕ Add Use Case" button
3. Fill form with name, stage, business area, description
4. Paste YouTube video URL (unlisted)
5. Save

### Via Database (Advanced):
```sql
-- Update use case stage
UPDATE ai_use_cases
SET stage = 'in-practice', stage_label = 'In Practice'
WHERE name = 'Work-Zone Impact Forecasting (LCPT + WZDx)';

-- Add video URL
UPDATE ai_use_cases
SET video_url = 'https://youtu.be/YOUR_VIDEO_ID'
WHERE name = 'Automated Incident Detection (TIMELI)';

-- Add benefits and risks
UPDATE ai_use_cases
SET
    benefits = 'Saves X hours per week, improves Y by Z%',
    risks = 'Requires human oversight, data quality dependent'
WHERE name = 'Your Use Case Name';
```
